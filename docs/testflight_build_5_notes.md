# TestFlight 1.0.0 (5)

## What to Test

This update adds reminder timezone choices, improves form consistency and amount
focus, and makes large currency values easier to read in the ledger.

- Reminders: choose Follow device timezone for local clock reminders, or a fixed
  timezone such as Eastern for the same alert instant across devices. Update all
  your synced devices before using fixed-timezone reminders. Check a reminder a
  few minutes ahead with system notifications enabled.
- Ledger: check large amounts, including currencies with long prefixes. Monthly
  summaries and transaction amounts should remain readable without hiding digits.
- Forms: check scheduled transactions, transfers, Fund/Goal allocations and
  returns, and balance adjustments. Amount focus and account selection should feel
  consistent; split allocations remain available.
- Settings: Help & Guides opens the online guides directly. Replay Onboarding
  remains available offline. Tap Last successful sync to view Sync Details.
- Continue checking normal entry, editing, synchronization, and reopening across
  your devices. Please report your device, the screen, and steps for any issue.

## Distribution intent

Upload build 5 for iOS/iPadOS and macOS and submit to the existing Private Beta
external group. Leave approved build 2 available; do not distribute build 4 or
expire older builds as part of this update. This is beta testing, not an App Store
release submission. Upload/review status must be verified separately.
